Responsive Design Principles

Fluid Layouts

Layouts that use relative units so elements scale with the viewport.

/* example */
.container {
  width: 90%;
  margin: 0 auto;
}

Flexible Media

Images, videos and media that resize and preserve aspect ratio.

img {
  max-width: 100%;
  height: auto;
  display: block;
}

Breakpoints

Use media queries to change layout at specific widths.

@media (max-width: 600px) {
  .grid { grid-template-columns: 1fr; }
}
Tip: Resize the window to see the layout change below 600px.
