Responsive CSS Cheat Sheet

Filters
Use filter: grayscale(), sepia(), blur(). Combine with transitions: filter: none; transition: filter 250ms;
Media Queries
@media (max-width: 700px) { ... } - change layout or typography for smaller screens.
Responsive Grid
Use CSS Grid: grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)) for fluid 2–3 columns.
Flexbox
Use display:flex with gap, align-items, justify-content. Use flex:1 to share space.
Typography
Scale fonts with clamp(): font-size: clamp(1rem, 2vw, 1.25rem); for readable text on all screens.
Spacing
Prefer gap for flex/grid spacing (no manual margin math). Use max-width & centered containers for readable lines.
Tip: resize the browser to see the grid convert to stacked rows under 700px.
