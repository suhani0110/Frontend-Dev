What is Responsive Design?

Responsive web design means building pages that adapt to different screen sizes. Use relative units (%, vw, rem), Flexbox for one-dimensional layouts, Grid for two-dimensional layouts, and media queries to change the layout at breakpoints.

  • Flexbox — great for navs and rows.
  • Grid — perfect for complex, 2D layouts.
  • Media queries — adjust layout under breakpoints (example: 700px).
  • Clamp() — makes typography responsive without many queries.

Cheat Sheet Preview

Filters
filter: grayscale(100%); transition: filter 200ms;
Media Queries
@media (max-width:700px) { ... }
Grid
grid-template-columns: repeat(auto-fit, minmax(220px,1fr));
Typography
font-size: clamp(1rem, 1.5vw, 1.25rem);
